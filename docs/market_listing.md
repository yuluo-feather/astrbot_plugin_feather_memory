## 短描述

为星羽塔罗记住你的偏好与近期关注主题，下次占卜时作为可选参考。

## 长描述

羽忆是星羽塔罗的可选记忆插件。它记住你主动保存的偏好、背景与目标，以及私聊普通占卜形成的近期主题，并在下一次占卜时把这份记忆作为可选上下文交给星羽。不安装羽忆时，星羽的行为完全不变。

- 两种来源：显式保存的短句 + 私聊普通占卜 / 单抽的固定主题。
- 不摄入群聊、不摄入今日牌运、不保存原始问题。
- 记忆正文只存在羽忆自己的 SQLite；与星羽只通过共享文件契约通信。
- 租约 + 两级开关：没有羽忆、租约失效或用户未授权时，星羽按“无记忆”运行。
- 可查看、单条删除、清空、随时关闭。

## 命令

| 命令 | 作用 |
|---|---|
| `/羽忆` / `/羽忆 查看` / `/羽忆 列表` | 查看主动保存与近期主题（私聊） |
| `/羽忆 记住 <内容>` | 保存偏好 / 背景 / 目标（自动开启总开关） |
| `/羽忆 修改 <id> <新内容>` | 修改一条主动保存；保留 id，可选前缀改分类 |
| `/羽忆 忘记 <id>` | 删除一条主动保存 |
| `/羽忆 清空` | 二次确认后删除**你自己**的已有数据（含导出副本）；不改变开关，要停止记录请用 `/羽忆 关闭` |
| `/羽忆 开启` | 一次打开总开关、自动历史、主题记录（只写一次授权） |
| `/羽忆 开启 自动` | 单项细调：自动历史（幂等） |
| `/羽忆 开启 主题` | 单项细调：主题枚举（幂等） |
| `/羽忆 关闭 自动` | 单项关闭：只关自动历史 |
| `/羽忆 关闭 主题` | 单项关闭：只关主题记录 |
| `/羽忆 关闭` | 全关并停止记录：删除 context 与待处理事件，授权写墓碑 |
| `/羽忆 状态` | 查看租约、开关、授权与 context |

## 部署前置

- AstrBot 若使用显式 `plugin_set` 列表，必须包含 `feather_memory`；否则插件可能已加载但指令 handler 会被过滤。
- 羽忆配置打开 `memory.enabled`；星羽塔罗侧打开 `memory.feed_enabled` 与 `memory.context_enabled`。
- 新用户先在私聊发 `/羽忆 开启`（一键打开总开关、自动历史与主题记录），再按需用 `关闭 自动` / `关闭 主题` 细调。
- 需要一个支持共享文件契约的星羽塔罗版本；版本号不在市场文案里写死，随羽忆 `metadata.yaml` 声明。

## 隐私说明

- 不监听全群消息、不保存全量聊天、不保存原始占卜问题。
- 事件文件除牌阵 / 牌面 / 主题外，还含事件 ID、平台与用户标识、时间与核心版本，用于去重与索引。
- 主题只取固定枚举（工作 / 学业 / 感情 / 家庭 / 财务 / 健康 / 人际 / 出行）；一句命中多个主题或无法归类时留空。
- 清空只删发起者自己的已有数据，不改变开关：已开启的继续记录，未开启的保持未开启；`users` 行保留开关与 `cleared_at`，用于挡住清空前的旧事件。要停止记录请用 `/羽忆 关闭`。
- 数据全部在本机 `data/plugin_data/`，不上传、不进市场包；宿主备份会包含它。
- 记忆作为不可信资料注入提示词，不覆盖系统提示。
- 请不要保存密码、令牌或账号凭据。

## 配置项

| 键 | 默认 | 说明 |
|---|---|---|
| `memory.enabled` | `false` | 羽忆全局开关；关闭时不写租约、不采集、不注入 |

## 数据与卸载

- SQLite：`data/plugin_data/feather_memory/feather_memory.sqlite3`
- 共享文件：`data/plugin_data/_shared/feather_memory/v1/`
- 卸载删除数据只删 `plugin_data/feather_memory/`；共享目录需手动清理或等待 TTL。
- 备份与恢复步骤见 [`backup_restore.md`](backup_restore.md)。
