# v0.1.0

- 首次实现羽忆插件：服务租约、用户授权、事件消费、SQLite 存储、双来源 context 合并。
- 命令：`/羽忆`、`导出`、`记住`、`修改`、`忘记`、`清空`、`开启`、`开启 自动`、`开启 主题`、`关闭`、`关闭 自动`、`关闭 主题`、`状态`。
- 默认登记（1a）：`memory.auto_enroll` 默认开启，新用户首次符合条件的私聊占卜先收到一次提示、从下一次起自动登记；租约新增可选 `auto_enroll`。停用改为写授权墓碑（`auto_history=false` / `store_topic=false`），不再删除授权；启动与每小时维护补齐缺失授权。清空只删已有数据、不改变开关：已开启的用户继续记录，未开启的保持未开启；要停止用 `/羽忆 关闭`。授权新增可选 `context_valid_after`（取 `cleared_at` / `disabled_at` 较晚者），核心据此拒绝旧 context；删除 context 失败时再改写为已过期作为第二道兜底。
- `/羽忆 导出`（仅私聊）：把本人记忆、近期主题统计与开关状态写成 `plugin_data/feather_memory/exports/` 下的 JSON，含数据版本、导出时间与数据类型，不含账号标识与原始问题；`/羽忆 清空` 会一并删除该用户的导出副本，每个用户只保留最近 5 份，导出不设条数截断，POSIX 下文件权限为 0600。
- `/羽忆 状态` 增补 context 有效性、revision、生成时间、字数 / 条数与最近一次消费时间。
- 上下文质量：主动保存上限 3 → 5，仍优先占位；新增 `context.min_topic_count`（默认 1，可设 2），只影响 context，不删除主题统计。
- `/羽忆 开启` 一次打开总开关、自动历史与主题记录，只写一次授权；`关闭 自动` / `关闭 主题` 可单项关闭。
- 隐私与可靠性修正：全局关闭时仍可 `/羽忆 关闭` / `/羽忆 清空`；清空使用 `/羽忆 清空 确认`；`忘记 #12` 可用；消费在 `BEGIN IMMEDIATE` 事务内复查 `enabled` / `auto_history` / `store_topic` / `cleared_at` / `disabled_at`；单项开关与 disable 条件更新；停用记录 `disabled_at`，重开后旧事件不复活。
- context 一致性：写后按快照 revision 条件清 dirty，状态转换用可重入锁 + `state.lock` 串行化；空/停用删除带 guard；新增 6 个 Event/Barrier 交错测试。
- 第二批加固：租约写删在 `lease.lock` 内复查 instance_id；context 校验 `generated_at` 与时钟偏差；WAL 只在初始化时设置；共享文件限长读取；启动/每小时记录只读统计（不设上限）。
- UX：`/羽忆 查看` / `查看记忆` / `列表` 等价于裸命令；新增 `/羽忆 修改 <id> <内容>`；帮助、忘记/记住用法与 `/羽忆 状态` 的「下一步」建议同步。
- 第三轮加固：auth/context/lease 清扫在各自锁内重读后删除；删除失败逐项回报并由每小时维护重试；分类前缀必须紧跟分隔符。
- 插件类定义在 `main.py`，AstrBot 才能正确绑定 `@filter.command` handler。
- 命令参数读取完整消息串，支持 `开启 自动`、`记住 偏好 …` 等带空格的参数。
- 契约 v1：`lease` / `auth` / `reading_event` / `memory_context` 四个共享 JSON。
